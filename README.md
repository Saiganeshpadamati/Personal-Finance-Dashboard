
# Personal Finance Dashboard

Personal Finance Dashboard is a modern and responsive personal finance dashboard built using React and TypeScript. It helps users manage transactions, track budgets, monitor expenses, and visualize their financial activities.

## Features
- Financial overview dashboard
- Add, edit, and delete transactions
- Track income and expenses
- Spending analytics and charts
- Budget management
- Responsive user interface
- Local data persistence

## Tech Stack
- React.js
- TypeScript
- Vite
- Tailwind CSS
- Redux Toolkit
- Recharts

## Run Locally

```bash
git clone https://github.com/Saiganeshpadamati/Personal-Finance-Dashboard/
cd FinFlow
npm install
npm run dev
```

## Purpose
Built as a frontend development portfolio project to demonstrate React, TypeScript, UI development, and state management skills.
